# 📊 Analyse des Plaintes Clients – Projet Data Analyst

## 🎯 Objectif du projet

Ce projet vise à analyser les plaintes clients dans un contexte télécom afin d’identifier les principaux problèmes opérationnels, d’évaluer la performance du service client et de détecter les clients à risque de churn.

---

## 🧩 Contexte

Dans le secteur des télécommunications, la gestion des plaintes clients est essentielle pour garantir la satisfaction et réduire le taux de résiliation.

Ce projet simule un cas réel d’entreprise où les données de plaintes sont analysées pour aider à la prise de décision.

---

## 📁 Dataset

Le dataset contient plus de 300 enregistrements avec les variables suivantes :

- ID de plainte  
- Date de plainte et de résolution  
- Type de plainte (Réseau, Facturation, Internet, Service client)  
- Canal (App, Email, Boutique, Appel)  
- Région  
- Statut (Résolue, En cours, Non résolue)  
- Niveau de satisfaction  

---

## 🛠️ Outils utilisés

- Power BI (visualisation & dashboard)
- Power Query (transformation des données)
- DAX (mesures et indicateurs)

---

## 📊 Dashboard

Le projet est structuré en deux pages :

### 🔹 Executive Summary
- Nombre total de plaintes  
- Taux de résolution  
- Temps moyen de résolution  
- Satisfaction moyenne  
- Analyse des plaintes par type, région et statut  

### 🔹 Analyse & Insights
- Performance des canaux de traitement  
- Temps de résolution par type de plainte  
- Satisfaction client selon le statut  
- Identification des clients à risque  

---

## 🧠 Insights clés

- Les plaintes liées au service client présentent les délais de résolution les plus élevés.  
- Les canaux digitaux (App, Email) sont plus performants que les canaux physiques.  
- Les plaintes non résolues ont un impact direct sur la satisfaction client.  
- Une proportion significative de clients présente un risque de churn.  

---

## 🚀 Recommandations

- Optimiser les processus du service client pour réduire les délais de traitement  
- Encourager l’utilisation des canaux digitaux plus performants  
- Mettre en place un suivi des plaintes non résolues  
- Développer des actions de rétention pour les clients à risque  

---

## 📌 Conclusion

Ce projet démontre l’importance de l’analyse des données dans l’amélioration de la satisfaction client et la prise de décision stratégique.
